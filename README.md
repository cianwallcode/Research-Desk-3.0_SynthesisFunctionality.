# 🏛️ Architectural Research Desk | V7.5

**A Digital Synthesis Portal for Irish Heritage and Environmental Risk.**

This project is a professional-grade research tool designed to bridge the gap between **Geographic Information Systems (GIS)** and **Architectural Typology**. It allows researchers to visualize historical and contemporary Irish sites, analyzing their physical boundaries against environmental data like flood risk.

---

## 🚀 Core Functionality

### 1. GIS Analysis Engine
* **Interactive Mapping:** Powered by Leaflet.js, featuring custom-styled pins for various architectural typologies.
* **Environmental Overlays:** Dynamic, toggleable layers for **Site Boundaries (Red)** and **Flood Risk Zones (Blue)**.
* **Drill-Down Workflow:** Transition from a global Irish context to high-resolution site-specific analysis via map-based popups.

### 2. Typological Filtering
* Sort sites instantly by category: **Cistercian**, **Museum**, or **Modernist**.
* Unified database management via a structured `database.js` file.

### 3. Integrated Research Workspace
* **Landing Page:** Professional entry point with project overview and branded "Start Project" navigation.
* **Data Inventory:** A master list of all research subjects with verified metadata.

---

## 🛠️ Technology Stack
* **Frontend:** HTML5, CSS3 (Custom Grid/Flexbox UI)
* **Mapping:** [Leaflet.js](https://leafletjs.com/)
* **Data:** JavaScript Object Notation (JSON-structured JS)
